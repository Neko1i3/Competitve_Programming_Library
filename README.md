# Competitive_Programming_Library
Personal Library of Data Structures and Algorithms for Competitive Programming in C++

All the codes were fully written by me, they are free to use for everyone. 

Contents include:

- Graph algorithms
- Data structures
- String algorithms
- Geometry
- Number theory

The implementations prioritize correctness and competitive programming usability rather than being production-ready. They are most often given as a part of a problem solution.
